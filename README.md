# MayDrama

MayDrama adalah aplikasi streaming drama berbasis **Flutter** yang menawarkan pengalaman menonton seru tanpa gangguan iklan. Untuk dapat memutar video di dalam aplikasi, pengguna wajib memiliki `access_key` yang valid.

---

## Fitur Utama

* **Bebas Iklan (No Ads):** Tonton drama favorit dari awal sampai akhir tanpa jeda iklan.
* **Akses Terkontrol:** Fitur pemutar video terkunci aman menggunakan sistem `access_key`.
* **Multiplatform:** Dibangun menggunakan Flutter, siap dijalankan di berbagai perangkat dengan performa yang mulus.

---

## Cara Mendapatkan Access Key

`access_key` berfungsi sebagai kunci utama agar video di dalam aplikasi dapat diputar. Kamu bisa mendapatkan kunci ini secara langsung dengan cara:

## Cara Instalasi & Menjalankan Proyek

### 1. Prasyarat
Sebelum memulai, pastikan perangkat kamu sudah terinstal:
* [Flutter SDK](https://docs.flutter.dev/get-started/install) (versi terbaru direkomendasikan).
* Android Studio / VS Code lengkap dengan ekstensi Flutter & Dart.

### 2. Kloning Repositori
```bash
git clone https://github.com/Kynonim/MayDrama.git
cd MayDrama
```

### 3. Instalasi Dependensi
Ambil semua packages yang dibutuhkan oleh Flutter:
```bash
flutter pub get
```

### 4. Jalankan Aplikasi
Hubungkan emulator atau perangkat fisik kamu, lalu jalankan perintah:
```bash
flutter run
```
